# Monte-Carlo
Project
## 📊 Monte Carlo Portfolio Risk Simulator

A **Monte Carlo Portfolio Risk Simulator** built in Python to analyze portfolio risk and simulate potential investment outcomes using historical stock market data.

### 🔍 Project Overview

This project uses historical price data for **AAPL, MSFT, GOOGL, AMZN, and NVDA** from 2020 to 2025. Monte Carlo simulation techniques are used to model possible portfolio outcomes and evaluate investment risk.

### 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* SciPy
* Matplotlib
* Seaborn
* yFinance
* Streamlit

### 📈 Key Features

* Downloaded historical stock market data using `yFinance`
* Analyzed historical stock prices and returns
* Applied Monte Carlo simulation for portfolio risk analysis
* Generated statistical measures and visualizations
* Evaluated potential portfolio outcomes under simulated scenarios

### 📂 Dataset

Historical stock market data for:

`AAPL | MSFT | GOOGL | AMZN | NVDA`

**Data Period:** January 2020 – December 2025

### ▶️ How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook or run it in Google Colab.
4. Execute the cells sequentially.

### 🎯 Objective

The objective of this project is to demonstrate the application of **Monte Carlo simulation, probability, statistics, and Python-based data analysis** for portfolio risk assessment.
